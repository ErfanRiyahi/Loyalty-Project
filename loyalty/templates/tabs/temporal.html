Temporal Stability needs 3 datasets — order, data, voice — each with 3 columns: MSISDN, date, and a marker column. The marker column name matters: it must be exactly "OrderStatusId" (order), "ACTUAL_USAGE" (data), or "Call_Duration" (voice). Leave a dataset address blank to use the backend's default file for that domain.
